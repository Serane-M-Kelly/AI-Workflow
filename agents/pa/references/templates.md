# Sources légères et livrables

Réutiliser les documents existants. Créer uniquement ce qui sert une décision, une preuve, une reprise ou un transfert. Les structures ci-dessous sont adaptables ; ne pas les produire toutes par défaut.

## État court / Passport

- Résultat demandé, type de travail et stade réel.
- Mandat actuel et source de la demande.
- Décisions acceptées et références propriétaires.
- Hypothèses importantes, limites et questions ouvertes.
- Travail actif, prochaine action et blocage éventuel.

## Hypothèse et preuve

| Hypothèse | Source, date et version | Observation ou témoignage | Interprétation et limite | Confiance motivée | Prochaine décision |
|---|---|---|---|---|---|

## Expérience

Question ; scénario ; participants réellement accessibles ; observations attendues ; temps/budget et limite d’effort ; conditions proposées ou acceptées de poursuite/correction/arrêt ; résultats réels ; conséquences.

## Parcours

| Tâche utilisateur | Déclencheur | Étapes et règles | États applicables | Fin réussie | Question à éprouver |
|---|---|---|---|---|---|

## Périmètre produit

Résultat ; cible ; inclus/exclus ; contenus ; parcours et règles ; exigences non fonctionnelles pertinentes ; critères testables ; preuves et limites ; contraintes ; décisions encore nécessaires. Fournir l’ordre et les dépendances produit utiles sans reproduire le backlog d’exécution.

## Décision

Objet ; statut proposé/accepté/remplacé ; décision et portée ; personne et source réelle ; date connue ; options et motifs utiles ; conséquences ; élément remplacé ou condition de réexamen. Une décision de Kelly ne peut être déduite d’un avis IA favorable.

## Changement

Demande réelle ; classification ; éléments affectés ; éléments préservés ; options ; décision applicable ; sources/version à mettre à jour ; prochaine action. Voir continuity.md.

## Synthèse de recherche

Décision éclairée ; faits sourcés ; contradictions ; hypothèses restantes ; conséquences pour le concept ; prochaine action. Mettre méthodes détaillées et sources secondaires en annexe seulement si utiles.

## Transmission

Pour le starter, utiliser le format exact de starter-handoff.md et le schéma fourni. Pour la direction visuelle, utiliser design-collaboration.md. Le fichier propriétaire contient les faits ; les documents de présentation et d’export référencent ou synthétisent ces sources à une version identifiée.
